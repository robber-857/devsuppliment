# RES 参数实验室

解压全部文件后双击 `index.html`，无需安装或联网。数据自动保存在当前浏览器。

## 当前算法

- 默认 a=250000、c2=0.2、d2=0.6、e1=1，其余可调值为 0。
- d1 自动等于 c1，不能独立输入。
- b = a*b1；c = cre*c1*c2；d = dre*c1*d2。
- e = a-b-cre*c1-dre*c1。
- res = (b + e*e1 + c + d) * (3.48/8)。
- 全程浮点计算，不执行 C 代码的 int 截断，显示最多 6 位小数。
- 趋势与敏感度遵循 d1=c1 联动；b1 的影响为 0.435*a*(1-e1)。

## 参数与注释

注释在参数旁编辑，自动保存。保存方案时一起保存该方案的注释快照，载入方案时恢复。载入方案后修改参数或注释，点击“更新当前方案”可保存到原方案，名称和顺序不变；也可点击“另存为新方案”。页面显示当前编辑对象及是否有修改。当前方案选择在刷新后保留；删除该方案、恢复初始参数或覆盖导入后取消选择，追加导入不改变选择。首个方案作为对比基准。

## 导入与换电脑

1. 旧电脑导出完整 JSON 备份，或导出 CSV 方案。
2. 将工具全部文件及备份文件复制到新电脑，打开 index.html。
3. 点击“导入 JSON / CSV”，选择文件，查看摘要和导入方式。

- **追加为新方案（默认）**：保留现有方案、当前参数和当前注释；新方案携带独立注释。同名自动加后缀。JSON 中的当前参数和注释若没有完全对应的方案，也会追加为方案。
- **覆盖现有数据**：替换当前参数、方案和注释。CSV 第一行作为当前参数。
- CSV 的每一行分别恢复为一个方案，支持中文、多行注释、逗号、引号及负数。缺少注释列时沿用本机对应注释。
- 旧文件或旧浏览器数据缺少 e1 时补为 1；d1 统一改为 c1；结果按最新公式重新计算。旧版本本地存储保留原副本。
- JSON 完整备份包含当前输入、所有方案和各自注释；CSV 导出已保存的方案，没有方案时导出当前输入。
- 文件校验失败不改变数据，确认导入前可以取消。

本工具不包含云端同步或用户登录。不同电脑之间通过文件迁移。

## 内置 Demo

Demo 来源是用户下载目录中最新导出的 `RES-方案对比 (1).csv`，包含“3个月20w项目_7.5w补助”方案及原始注释；不是自动化测试数据。它是该导出文件的快照，不是实时浏览器数据。旧文件没有 e1，迁移时补为 1，d1 与 c1 联动，结果按当前公式计算。

- 新浏览器没有任何版本的本地存储时，首次打开自动载入 Demo。
- 已有数据不覆盖；可点击“载入 Demo”，选择追加或覆盖。
- `demo/demo-backup.json` 可通过现有 JSON 导入功能恢复。
- `demo/demo-data.js` 提供离线初始化，与 JSON 内容一致；复制或解压工具时保留 demo 目录。
